# Прогноз погоды по IP

Консольное приложение на Python, которое автоматически определяет
местоположение по IP-адресу, получает прогноз погоды на 5 дней
и сохраняет агрегированные данные в SQLite и Markdown-отчёт.

## Что делает программа

1. Определяет город и координаты по вашему IP через [ipinfo.io](https://ipinfo.io).
2. Запрашивает прогноз погоды на 5 дней с шагом 3 часа через
   [OpenWeatherMap 5 day / 3 hour forecast](https://openweathermap.org/api/forecast5).
3. Агрегирует 3-часовые точки по календарным дням:
   минимальная и максимальная температура, средняя влажность,
   максимальная скорость ветра, описание погоды.
4. Оставляет прогноз на сегодня + 3 следующих дня (4 дня).
5. Сохраняет результат в базу данных SQLite (`weather.db`),
   пропуская дубликаты по паре «город + дата».
6. Формирует Markdown-отчёт `forecast.md` с таблицей прогноза.

## Технологии

- **Python 3.10+**
- **requests** — HTTP-запросы к API
- **python-dotenv** — загрузка секретов из `.env`
- **SQLAlchemy 2.0** — ORM и работа с БД
- **SQLite** — встроенная база данных (файл `weather.db`)

## Используемые API

- **ipinfo.io** — геолокация по IP. Бесплатный тариф: 1000 запросов в сутки без токена,
  50 000 в месяц с бесплатным токеном.
- **OpenWeatherMap** — прогноз погоды. Бесплатный тариф:
  60 запросов в минуту, 1 000 000 в месяц.

## Установка

git clone https://github.com/ваш-логин/weather-forecast.git
cd weather-forecast
```

```

```bash
pip install -r requirements.txt
```

## Настройка

### 1. Получите API-ключи

**ipinfo.io (опционально):** зарегистрируйтесь на [ipinfo.io](https://ipinfo.io/signup)
и скопируйте токен из личного кабинета. Без токена тоже работает,
но лимит ниже — 1000 запросов в сутки.

**OpenWeatherMap (обязательно):** зарегистрируйтесь на
[openweathermap.org](https://openweathermap.org/api), подтвердите email
и скопируйте ключ со страницы [API keys](https://home.openweathermap.org/api_keys).
Новый ключ активируется в течение 10–60 минут, до этого запросы
будут возвращать `401 Unauthorized`.

### 2. Создайте `.env` по шаблону

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```env
# ipinfo.io
API_KEY=ваш_токен_ipinfo
BASE_URL=https://ipinfo.io/json

# OpenWeatherMap
API_KEY_WEATHER=ваш_ключ_openweathermap
BASE_URL_WEATHER=https://api.openweathermap.org/data/2.5/forecast

# База данных
DATABASE_URL=sqlite:///weather.db
```

### 3. Параметры БД

По умолчанию используется SQLite-файл `weather.db` в корне проекта.
Он создаётся автоматически при первом запуске — ничего настраивать не нужно.
Если хотите другое расположение, измените `DATABASE_URL` в `.env`.

### Назначение модулей

| Файл | Что делает |
|------|-----------|
| `geo_locator.py` | Функция `check_ip()` — запрашивает ipinfo.io, возвращает словарь с IP, городом и координатами `lat`/`lon` |
| `weather_client.py` | `get_forecast()` — запрос к OpenWeatherMap; `aggregate_forecast()` — группировка по дням и расчёт статистики |
| `database.py` | Класс `Base`, модель `WeatherForecast`, движок SQLAlchemy, `SessionLocal`, создание таблицы |
| `save_forecast.py` | `save_forecast(city, days)` — вставка через `INSERT OR IGNORE`, возвращает (вставлено, пропущено) |
| `markdown_export.py` | `export_to_markdown(city, path)` — формирование `.md`-отчёта с таблицей |
| `main.py` | Последовательно вызывает все шаги и печатает итог |

## Возможные проблемы

**`401 Unauthorized` от OpenWeatherMap** — ключ ещё не активировался.
Новые ключи начинают работать через 10–60 минут после регистрации.

**`429 Too Many Requests`** — превышен лимит запросов.
Подождите минуту или добавьте токен ipinfo, чтобы поднять суточный лимит.

**`ModuleNotFoundError`** — запускаете не из корня проекта
или не активировали виртуальное окружение.

**Пустой прогноз** — IP определился как хостинг или VPN,
для таких адресов OpenWeatherMap может не иметь данных.
Попробуйте запустить с другого подключения.
